# Agent Tool Usage

현재 실행 중인 도구에 해당하는 절과 공통 실행 원칙만 적용한다. 설치된 기능·모델·에이전트는 현재 세션에서 확인한다.

## Codex

AGENTS.md의 Codex Usage를 구체화한다. `claude-code-usage`는 두 도구에 공통으로 배포하는 스킬 식별자이며, 이 절은 Codex용 규약이다.

- 계획·실행·검증은 현재 세션의 도구와 모드를 따른다. 다른 에이전트 제품의 도구 이름이나 명령을 요구하지 않는다.
- 사용자가 `$<name>` 또는 스킬 이름을 지정하면 세션 목록에서 실제 위치를 찾아 `SKILL.md`를 읽는다. 필요한 참조 파일만 추가로 읽는다.
- 프로젝트 지침은 저장소에서, 사용자 스킬은 세션에 제공된 경로에서 찾는다. `skills/<name>/...`는 해당 스킬의 실제 위치로 해석한다.
- 작업 추적 도구가 있으면 복잡한 작업의 진행 상태를 갱신한다. 없으면 짧은 계획과 진행 보고로 추적한다.
- 연결 도구는 현재 세션의 검색·조회 방식으로 스키마를 확인한 뒤 호출한다.

## 공통 실행 원칙

- 전역 지침의 계획·Git 안전·보안 규칙을 따른다. 이미 받은 권한을 반복 요청하지 않고, 권한 범위를 확대하지 않는다.
- 독립적인 읽기·검색·검사는 병렬로 처리한다. 이전 결과가 다음 입력이면 순차로 실행한다. 같은 파일의 수정은 한 담당자가 수행한다.
- 장기 실행은 제공된 백그라운드·대기 기능을 사용하고, 짧은 간격의 반복 조회를 피한다.
- 대형 출력은 관련 위치와 필요한 구간만 읽는다. 컨텍스트가 부족하면 목표·결정·변경·검증·남은 작업을 보존한다.
- 현재 선택된 모델을 기본으로 사용하고, 전환은 현재 세션에서 허용한 조건과 제공된 모델을 따른다.

## Subagents / 서브에이전트

- 위임 도구와 권한이 있는 경우 목표·산출물·검증 방법이 명확한 독립 작업만 위임한다.
- 각 에이전트에 필요한 맥락·기준·파일 담당을 전달하고 같은 탐색을 중복하지 않는다.

## 검증과 보고

- 저장소의 검사 명령을 우선하고 실패 처리는 `skills/validate/SKILL.md`를 따른다. 읽기 전용 작업에서 임의로 수정하지 않는다.
- UI 변경은 가능하면 dev 서버와 브라우저로 주요 사용자 흐름을 확인한다. 직접 확인하지 못했으면 UI 검증 미완료임을 밝힌다.
- 서브에이전트 결과는 근거와 전체 diff로 검토하고, 메인이 요구사항 충족과 최종 검증을 책임진다.

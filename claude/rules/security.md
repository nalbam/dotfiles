# Security

보안 영향이 있는 변경에 적용한다. 인증·권한·암호화·PII·결제·외부 시스템 인증 정보 관련 작업은 실행 전 영향 범위를 사용자에게 확인한다. 이미 승인된 범위는 다시 묻지 않는다.

## 시스템 경계

- 외부 입력을 검증하고 SQL·명령·경로·HTML 등 사용 맥락에 맞는 주입 방어를 적용한다.
- 인증·권한은 서버에서 검증한다. 쿠키 기반 요청의 CSRF, 공개 엔드포인트의 악용·요청 제한 등 해당 구조에 필요한 방어를 확인한다.
- 최소 권한을 사용하고 시크릿·개인정보를 코드·로그·오류 메시지·커밋·PR에 노출하지 않는다.

## Secret Management

- 시크릿은 환경변수 또는 시크릿 매니저로 전달한다. 실제 값이 있는 `.env`는 추적하지 않고 `.env.example`에는 비밀이 아닌 예시만 둔다.
- 필요한 시크릿이 없으면 명확한 오류로 드러낸다. 값 자체를 출력하지 않는다.
- 노출 발견 시 추가 노출을 막고 값 자체를 반복하지 않은 채 알린다. 코드에서 지우는 것만으로 해결되지 않으므로 폐기·재발급을 권한 범위 안에서 처리한다.
- 취약점은 실제 영향과 근거로 보고하고 승인된 범위에서 수정한다. 무관한 작업을 일괄 중단하거나 권한 밖 보안 변경을 수행하지 않는다.
